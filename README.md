**JS Calculator** is a sleek, responsive, and lightweight client-side calculator web application built with vanilla JavaScript and styled using the modern Bootstrap 5.3.3 framework. It provides basic arithmetic operations within a minimal, mobile-friendly interface.

## Features
- **Responsive Layout:** Clean UI centered on the screen, optimized for mobile and desktop screens.
- **Arithmetic Operations:** Supports addition (+), subtraction (-), multiplication (×), and division (/).
- **Parentheses Support:** Handles grouped mathematical expressions using `(` and `)`.
- **Keyboard & Touch Ready:** Large touch-friendly button grid for quick entries.
- **Clear & Backspace:** Quick reset functionality (`C`) and single-character deletion (`⌫`).

## Installation
No installation or complex build step required. Simply clone the repository or download `js-calculator.html` and open it directly in any modern browser.

```bash
git clone https://github.com/webkolog/js-calculator.git

```

## Usage

Open `js-calculator.html` in your web browser:

1. Click or tap any numerical button to start inputting values.
2. Select operators (`+`, `-`, `*`, `/`) and optionally group terms with `(` or `)`.
3. Press `=` to calculate the output expression.
4. Press `⌫` to fix typing errors or `C` to reset the input line completely.

## Project Structure

* `js-calculator.html` - Contains the HTML markup, Bootstrap CDN linkages, custom layout styling, and inline JavaScript evaluation logic.

## Dependencies

* **Bootstrap 5.3.3** (Loaded via CDN)
* Standard Modern Web Browser with JavaScript enabled.
